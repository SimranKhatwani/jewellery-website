# AURELLE — Fine Silver Jewellery
### 925 Sterling Silver Atelier & Digital Catalogue

A digital showcase for **AURELLE**, an art-directed luxury fine jewellery brand presenting solid 925 sterling silver rings and delicate chain anklets for international collectors.

---

## ✦ Brand & Catalogue Overview

* **Artisanal Medium:** Solid 925 Sterling Silver with hallmarked purity, hand-stippled satin finishes, and protective rhodium micro-barriers.
* **Curated Collections:**
  * **Sculptural Silver Rings:** Organic molten bands, ergonomic contour waves, and architectural signets.
  * **Delicate Silver Anklets:** Featherlight flat curb chains, silky snake ribbons, and satellite beaded anklets.
* **Distribution & Acquisitions:** Catalogue model distributed through **RKB Enterprises**, with collections also available on **Amazon** and **Flipkart**. Direct WhatsApp and Email studio inquiry triggers pre-fill product details, sizing, and finishes.

---

## ✦ Visual Design System (Silver Tarakaya Aesthetic)

The visual direction features a warm, tactile palette:

| Token | Hex | Role |
| :--- | :--- | :--- |
| **Warm Taupe** | `#9A8E78` | Top moving marquee ticker, collection badges, design notes, and borders |
| **Muted Mocha** | `#93826E` | Primary interactive buttons, active filter tabs, and hover states |
| **White** | `#FFFFFF` | Primary canvas, card backplates, and contrast elements |
| **Soft Stone** | `#E4E1DB` | Subtle image frame backdrops, thumbnail backplates, and modal surfaces |
| **Muted Charcoal** | `#6C6658` | Luxury display serif headings, body typography, and modal overlays |

* **Typography:** *Cormorant Garamond* (Editorial Display Headings) and *Plus Jakarta Sans* (Body & Technical Data).

---

## ✦ Key Features

* **Infinite Marquee Announcement Bar:** GPU-accelerated moving ticker with interactive pause on hover.
* **Campaign Hero Slideshow:** Full-width photographic carousel with touch swipe and category deep links.
* **Hand-Drawn Benefits Banner:** Fine monochrome pencil-sketch craft and service illustrations.
* **Deep Product Detail Pages (PDP):** Interactive zoom magnifier lens, multi-angle thumbnails, finish selectors, US ring sizing / anklet drape guides, and technical purity specifications.
* **Local Wishlist Drawer:** Client favorites drawer with total selection value calculation (persisted to `localStorage`).
* **Instant Studio Search:** Real-time filter across categories, silhouette names, and metallurgical finishes.

## ✦ Getting Started

### Prerequisites
* **Node.js** (v18+ recommended)
* **npm**

### Installation & Development

```bash
# 1. Install dependencies
npm install --legacy-peer-deps

# 2. Start the local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Other Commands

```bash
# Validate TypeScript types
npm run lint

# Build production bundle (dist/)
npm run build

# Preview production build locally
npm run preview
```
