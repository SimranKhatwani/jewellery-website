# AURELLE — Fine Silver Jewellery

A digital showcase for **AURELLE**, an art-directed luxury fine jewellery brand presenting solid 925 sterling silver rings and delicate chain anklets for international collectors.

## ✦ Tech Stack

* **Framework:** React 19
* **Build Tool:** Vite 8
* **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
* **Language:** TypeScript
* **Icons:** Lucide React
